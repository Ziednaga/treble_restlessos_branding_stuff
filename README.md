This repository contains the official branding artwork, logo elements, and boot animation content for the RestlessOS Treble GSI project, maintained by @cawilliamson.

## Contents
- `/Branding/LogoElements/` — logo variants
- `/Branding/BootAnimation/` — boot animation assets
- `/GitElements/` — banners and assets used across RestlessOS repositories
- `/Obsolete/` — legacy and discarded branding concepts
